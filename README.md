# Discord Toys

Small, silly bots and tools for our Discord server. The goal is to make the server more fun, not to build a giant bot platform.

Ideas include goofy chat rules, tiny games, and other bits of server nonsense. We’ll pick one small thing at a time, agree how it should behave, then build and try it.

Project notes live in [`_project/`](./_project/). Start with the [handoff](./_project/HANDOFF.md) and [project profile](./_project/PROJECT_PROFILE.md).
